# Synergy AI Integration

Интеграции искусственного интеллекта в бизнес-процессы университета «Синергия».

## 📌 О проекте
Проект представляет собой готовый **End-to-End (E2E) пайплайн**, демонстрирующий полный цикл работы с данными: 
`Сбор реальных данных -> Очистка -> NLP-анализ -> Генерация отчетов`.
Решение спроектировано с учетом современных требований к импортозамещению и безопасности данных (использование GigaChat от Сбера).

**Основные компоненты:**
1. **ИИ-ассистент приёмной комиссии / поддержки** (`src/chatbot`): 
   Работает по технологии RAG (TF-IDF + контекст). Поддерживает интеграцию с LLM **GigaChat**. Если ключ API не указан или сервис недоступен, автоматически переключается в офлайн-режим (FAQ-фолбэк).
2. **Модуль автосбора и анализа обратной связи** (`src/scraper.py` + `src/feedback_analysis`): 
   Асинхронный скрипт на базе `Playwright` автоматически собирает реальные отзывы об университете с Яндекс.Карт, удаляет дубликаты и проводит лексиконный анализ тональности (Sentiment Analysis) с тематической классификацией жалоб.
3. **Корпоративные интеграции** (`src/integration`): 
   Мок-клиенты (заглушки), имитирующие обмен данными с СЭД **Directum RX** (создание тикетов при сбое ИИ) и **LMS** (загрузка данных о прогрессе студентов из CSV и выявление «зоны риска»).
