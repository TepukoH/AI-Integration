# Synergy AI Integration

Пилотный проект интеграции искусственного интеллекта в бизнес-процессы
Московского университета «Синергия».

## 📌 Описание проекта
Проект представляет собой готовый **End-to-End (E2E) пайплайн**, демонстрирующий полный цикл работы с данными и искусственным интеллектом: 
`Сбор реальных данных -> Очистка -> NLP-анализ -> Генерация отчета`.

**Основные компоненты:**
1. **ИИ-ассистент приёмной комиссии / поддержки** (`src/chatbot`): 
   Работает по технологии RAG (TF-IDF + контекст). Поддерживает интеграцию с российской LLM **GigaChat** от Сбера. Если ключ API не указан или сервис недоступен, автоматически переключается в офлайн-режим (FAQ-фолбэк).
2. **Модуль автосбора и анализа обратной связи** (`src/scraper.py` + `src/feedback_analysis`): 
   Скрипт на базе `Playwright` автоматически собирает реальные отзывы об университете с Яндекс.Карт, удаляет дубликаты и проводит лексиконный анализ тональности (Sentiment Analysis) с тематической классификацией жалоб.
3. **Мок-интеграции** (`src/integration`): 
   Эмуляция обмена данными с СЭД Directum RX (создание тикетов) и LMS (выявление студентов в «зоне риска»).
