# 03. Архитектура решения
В основе проекта лежит событийно-ориентированный E2E-пайплайн (End-to-End), разделенный на три независимых контура.

```mermaid
flowchart LR
    %% Контур 1: ИИ-ассистент
    U[Студент / Абитуриент] -->|чат| BOT[ИИ-ассистент]
    BOT --> KB[(База знаний FAQ)]
    BOT -.опционально.-> GC[GigaChat API от Сбера]
    
    %% Контур 2: Сбор и анализ отзывов
    YM[Яндекс.Карты] -->|Playwright| SCR[Модуль парсинга]
    SCR -->|CSV| FB[(Датасет отзывов)]
    FB --> AN[Модуль NLP-анализа]
    AN --> REP[Markdown-отчет]

    %% Контур 3: Корпоративные интеграции
    LMS[(LMS ВУЗа / CSV)] --> PRED[Модуль предиктивной аналитики]
    PRED -->|Список 'в зоне риска'| DRX[Directum RX / Мок-клиент]
    BOT -->|Создать тикет| DRX
